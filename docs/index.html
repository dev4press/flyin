About Flyin

Flyin is a modernized, lightweight popup library designed for developers who need flexibility and performance. It provides a robust core for creating everything from simple notifications to complex interactive dialogs.

TypeScript Core

Written in TypeScript for excellent developer experience and type safety.

Modern SCSS

Fully themeable using CSS variables and modular SCSS partials.

Accessibility

Built-in focus management and WAI-ARIA support for inclusive design.

Zero Dependencies

Minimal footprint with only js-cookie as an external requirement.

Modern Build

Vite-powered build system ensures optimized bundles and fast loading.

Evergreen Support

Optimized for modern browsers with no legacy IE baggage.

Installation

You can install Flyin via npm:

npm install @dev4press/flyin
