Files for the menu are organized into several folders.

Demos

Folder 'demo' contain examples for popups.

Distribution

For wide range of loading options, plugin has several distribution options available.

Modern Build (dist)

Folder 'dist' contains the modernized build files.

  • smart-animated-popup.css: main plugin style file.
  • smart-animated-popup.umd.js: Universal Module Definition (for browsers and jQuery).
  • smart-animated-popup.es.js: ES Module version.

Third Party libraries:

  • js-cookie: must be loaded for cookie-based features.
