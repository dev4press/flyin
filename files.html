Files for the menu are organized into several folders.

Demos

Folder 'demo' contain examples for popups.

Distribution

For wide range of loading options, plugin has several distribution options available.

Compressed

Folder 'dist' contains compressed files you need to include with your project.

  • popup.core.min.css: main plugin style file.
  • popup.core.min.js: main plugin script file.

Third Party libraries are in 'libs' folder.

  • libs/base.min.js: must be loaded before main plugin JS files.
  • libs/jquery.cookie.min.js: support for cookies based features.

Packed

Folder 'pack' contains compressed and packed files you need to include with your project.

  • popup.pack.css: full styles pack.
  • popup.pack.js: Base.js, Cookie, main jQuery code.
