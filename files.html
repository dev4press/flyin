Files for the menu are organized into several folders.

Demos

Folder 'demo' contain examples for popups.

Distribution

Flyin is available as a zero-dependency library (except for js-cookie).

Modern Build (dist)

Folder 'dist' contains the modernized build files.

  • flyin.css: main library style file.
  • flyin.umd.js: Universal Module Definition (for browsers).
  • flyin.es.js: ES Module version.

Third Party libraries:

  • js-cookie: must be loaded for cookie-based features.

Sources

Folder 'source' contains legacy source files. New source code is in 'src' folder.
