About Flyin

Flyin is a modernized popup library for creating normal or modal popups with custom positioning, animation effects, and customized looks. It is a complete rewrite of the Smart Animated Popup library, focusing on performance, type safety, and modern web standards.

TypeScript Core

Completely rewritten for type safety and modern standards.

SCSS Styles

Modular styles with variables and nesting for easy customization.

Zero Dependencies

Standalone version (only requires js-cookie).

Modern Build

Powered by Vite for fast development and small bundles.

No IE Support

Focused on modern browsers (Chrome, Firefox, Safari, Edge).

Installation

You can install Flyin via npm:

npm install @dev4press/flyin

How to Use

1. Prepare popup content: Create a DIV with popup content and hide it using inline style:

<div id="my-popup" data-title="Flyin Popup" style="display: none;">
    <p>Popup Content</p>
</div>

2. Load Library Files: Include the CSS and JavaScript files in your HTML:

<!-- Load Styles -->
<link rel="stylesheet" href="dist/flyin.css">

<!-- Load Scripts -->
<script src="dist/js.cookie.min.js"></script>
<script src="dist/flyin.umd.js"></script>

3. Initialize Flyin: Initialize the popup in your JavaScript:

<script>
    document.addEventListener('DOMContentLoaded', function() {
        new Flyin("#my-popup", {
            settings: {
                effect: 'bounce',
                style: 'flyin-style-plain-white'
            }
        });
    });
</script>
