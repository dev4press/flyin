Keyboard Shortcuts

This example demonstrates how to use keyboard shortcuts to open and close the popup using the keysOpen and keysClose settings.

Try the following shortcuts:

Control + Shift + F

to Open

Control + Shift + C

to Close

This popup can be opened and closed using keyboard shortcuts!

We are using the tinykeys library internally to handle these bindings.
