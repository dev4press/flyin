Flyin is a modernized popup library for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.

Library has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.

Notice: Flyin is a zero-dependency library (except for js-cookie).

Step 1: Loading styles - add the following lines into header of the page, and adjust paths to match the location for files:

<link rel="stylesheet" type="text/css" href="dist/flyin.css">

Step 2: You need content to put into popup. This has to be a DIV type block with content inside. You also should set display for it to none. And if you want, set data-title to title to show on popup:

<div id="flyin-example" data-title="Flyin Popup" style="display: none;">
  <p>Flyin is a modernized popup library for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.</p>
  <p>Library has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.</p>
</div>

Step 3: Load & run Flyin - You need to load JS Cookie and the library script:

<script type="text/javascript" src="https://cdn.jsdelivr.net/npm/js-cookie@3.0.5/dist/js.cookie.min.js"></script>
<script type="text/javascript" src="dist/flyin.umd.js"></script>
<script type="text/javascript">
  document.addEventListener('DOMContentLoaded', function() {
    const popup = new Flyin("#flyin-example");
    popup.open();
  });
</script>
