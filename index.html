Smart Animated Popup is a jQuery powered plugin for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.

Plugin has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.

Notice: There are different ways to load files needed by this plugin. This page contains 2 most common examples.

Step 1: Loading styles - add the following lines into header of the page, and adjust paths to match the location for files:

<link rel="stylesheet" type="text/css" href="dist/popups.core.min.css">

Step 1a: Or you can load packed file:

<link rel="stylesheet" type="text/css" href="pack/popup.pack.css">

Step 2: You need content to put into popup. This has to be a DIV type block with content inside. You also should set display for it to none. And if you want, set data-title to title to show on popup:

<div id="sanip-example" data-title="Smart Animated Popup" style="display: none;">
  <p>Smart Animated Popup is a jQuery powered plugin for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.</p>
  <p>Plugin has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.</p>
</div>

Step 3: Load & run jQuery plugin - You need to load jQuery, Base.js, Knob.js (if you want to use Circular skin), plugin Core and Skings scripts:

<script type="text/javascript" src="https://code.jquery.com/jquery-1.12.4.min.js"></script>
<script type="text/javascript" src="dist/libs/base.min.js"></script>
<script type="text/javascript" src="dist/libs/jquery.cookie.min.js"></script>
<script type="text/javascript" src="dist/popup.core.min.js"></script>
<script type="text/javascript">
  jQuery(document).ready(function() {
    jQuery("#sanip-example").smartAniPopup();
  });
</script>

Step 3A: Or you can load everything with one file (plus jQuery):

<script type="text/javascript" src="https://code.jquery.com/jquery-1.12.4.min.js"></script>
<script type="text/javascript" src="pack/popup.pack.js"></script>
