Smart Animated Popup is a jQuery powered plugin for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.

Plugin has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.

Example #01: This example opens popup automatically 5 seconds after page load, and will also open it if your mouse leaves the page. It sets one of the extra styles and effect is set to fall right. Popup is set to appear in the page bottom right.

<script type="text/javascript">
  jQuery(document).ready(function() {
    jQuery("#sanip-example").smartAniPopup({
    settings: {
      style: "sanp-style-box-red sanp-button-alt",
      positionX: "right",
      positionY: "bottom",
      onLoadDelay: 5000,
      onLeaveViewport: true,
      effect: "fallright",
      width: "35%",
      minWidth: "500px",
      offsetX: "20px",
      offsetY: "20px"
    }
    });
  });
</script>
