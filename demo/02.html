Smart Animated Popup is a jQuery powered plugin for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.

Plugin has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.

Example #02: This example opens popup automatically 2 seconds after page load, and it will close it after 5 seconds. It sets one of the extra styles and effect is set to random. Popup is set to appear in the middle of the page. This example uses cookie to store the number of times popup is displayed, and it will show it 3 times (refresh page 4 times, and the last time it will not show it, and it will not show it for a day).

<script type="text/javascript">
  jQuery(document).ready(function() {
    jQuery("#sanip-example-demo-02").smartAniPopup({
    settings: {
      style: "sanp-style-clean-gray"
      onLoadDelay: 2000
      closeAuto: true
      closeAutoDelay: 5000
      width: "40%"
      minWidth: "320px"
      cookieCode: "sap-demo-02"
      autoShowLimit: true
      autoShowCounter: 3
      autoShowDelay: 1
    }
    });
  });
</script>
