Flyin is a modernized popup library for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.

Library has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.

...and this is custom footer

Example #05: This example shows how can you easily set custom header and footer for the popup, in this case by taking parts of the target DIV.

<script type="text/javascript">
  document.addEventListener('DOMContentLoaded', function() {
    new Flyin("#flyin-example-demo-05", {
      settings: {
        style: "flyin-style-box-red",
        headerContent: document.querySelector("#flyin-example-demo-05 h5").innerHTML,
        footerContent: document.querySelector("#flyin-example-demo-05 footer").innerHTML,
        positionX: "left",
        positionY: "bottom",
        onLeaveViewport: true,
        width: "35%",
        minWidth: "500px",
        offsetX: "20px",
        offsetY: "20px"
      }
    });
  });
</script>
