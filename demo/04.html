Smart Animated Popup is a jQuery powered plugin for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.

Plugin has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.

Example #04: This example doesn't have auto open/close active, and it is not modal popup with overal, and ESC is not closing the popup. But, you have buttons to open/close the popup and to show it's status based on the callback functions.

|
Event Fired: /
Popup Status: closed
<script type="text/javascript">
  jQuery(document).ready(function() {
    jQuery("#snap-open-popup").click(function(){
      jQuery("#sanip-example-demo-04").smartAniPopup("open");
    });

    jQuery("#snap-close-popup").click(function(){
      jQuery("#sanip-example-demo-04").smartAniPopup("close");
    });

    jQuery("#sanip-example-demo-04").smartAniPopup({
      callbacks: {
        beforeOpen: function(obj){
          jQuery("#span-event").html("beforeOpen");
          jQuery("#span-status").html(obj.get("status"));
        },
        afterOpen: function(obj){
          jQuery("#span-event").html("afterOpen");
          jQuery("#span-status").html(obj.get("status"));
        },
        beforeClose: function(obj){
          jQuery("#span-event").html("beforeClose");
          jQuery("#span-status").html(obj.get("status"));
        },
        afterClose: function(obj){
          jQuery("#span-event").html("afterClose");
          jQuery("#span-status").html(obj.get("status"));
        }
      },
      settings: {
        modal: false,
        closeEscape: false,
        onLoad: false,
        footer: false,
        positionX: "right",
        positionY: "bottom",
        width: "30%",
        minWidth: "320px"
      }
    });
  });
</script>
