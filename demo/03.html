Smart Animated Popup is a jQuery powered plugin for creating normal or modal popups with custom positioning, popup open/close animation effect, customized overlay and popup looks, tons of settings. And it's responsive.

Plugin has over 20 animation effects you can assign, with additional 'random' effect that will pick random effect on every page load.

Example #03: This example opens popup automatically 1 seconds after page load. This popup has no header or footer, it has custom overaly and click on overlay will not close the popup. It uses cookie again to show popup 20 times.

<script type="text/javascript">
  jQuery(document).ready(function() {
    jQuery("#sanip-example-demo-03").smartAniPopup({
    settings: {
      style: "sanp-style-plain-black"
      onLoadDelay: 1000
      footer: false
      header: false
      closeOverlay: false
      overlayActive: true
      overlayColor: "#660000"
      overlayOpacity: 1
      width: "40%"
      minWidth: "320px"
      cookieCode: "sap-demo-03"
      autoShowLimit: true
      autoShowCounter: 20
      autoShowDelay: 1
    }
    });
  });
</script>
